# BiHome Backend — Spring Boot

Đọc `../CLAUDE.md` trước (quy ước chung), và `../docs/SPEC.md` cho nghiệp vụ.

## Lệnh thường dùng

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=local   # chạy local
./mvnw clean verify                                       # build + test + check
./mvnw test -Dtest=BuildingServiceTest                    # chạy 1 test
./mvnw test -Dtest='*IT'                                  # integration test (Testcontainers Oracle)
```

## Phiên bản & thư viện

- Java 21, Spring Boot 3.5.x, Maven wrapper.
- `spring-boot-starter-web, -data-jpa, -security, -validation, -actuator`
- `com.oracle.database.jdbc:ojdbc11`
- `org.flywaydb:flyway-core` + `org.flywaydb:flyway-database-oracle` (bắt buộc với Flyway 10+)
- `io.jsonwebtoken:jjwt-api/-impl/-jackson` 0.12.x
- `org.mapstruct:mapstruct` 1.6.x + processor, `lombok` (khai báo annotationProcessorPaths đúng thứ tự: lombok → lombok-mapstruct-binding → mapstruct-processor)
- `org.springdoc:springdoc-openapi-starter-webmvc-ui` 2.x
- `org.apache.poi:poi-ooxml` (import/export Excel)
- Test: `spring-boot-starter-test`, `spring-security-test`, `org.testcontainers:oracle-free`

## Quy tắc tầng

- Controller: chỉ nhận/validate request (`@Valid`), gọi service, trả DTO. Không chứa logic, không trả entity.
- Service: `@Transactional(readOnly = true)` ở class, `@Transactional` ở hàm ghi. Toàn bộ rule nghiệp vụ nằm đây.
- Repository: không viết native SQL nếu JPQL/Specification làm được. Dùng `@EntityGraph` hoặc fetch join để tránh N+1 cho list.
- Ném `BusinessException(ErrorCode, message tiếng Việt)` cho lỗi nghiệp vụ; `NotFoundException` khi không thấy bản ghi (kể cả khi bản ghi thuộc tòa nhà khác — không để lộ sự tồn tại).

## Entity & Oracle

- `BaseEntity`: `id` (`NUMBER(19) GENERATED BY DEFAULT AS IDENTITY`), `createdAt`, `updatedAt` (`@CreatedDate/@LastModifiedDate`, kiểu `OffsetDateTime`), `createdBy`, `updatedBy` (`@CreatedBy` từ `AuditorAware` lấy username), `version` (`@Version`).
- `BuildingScopedEntity extends BaseEntity`: thêm `building` (`@ManyToOne(fetch = LAZY)`, cột `BUILDING_ID`).
- Tên bảng/cột: UPPER_SNAKE_CASE, số ít (`BUILDING`, `APARTMENT`, `ASSET_ITEM`). Bảng user là `APP_USER`.
- Kiểu dữ liệu: chuỗi `VARCHAR2(n CHAR)` (bắt buộc `CHAR` để lưu tiếng Việt đúng độ dài), số tiền `NUMBER(19,2)`, boolean `NUMBER(1)` + `CHECK (col IN (0,1))`, enum `VARCHAR2(30 CHAR)` + `@Enumerated(STRING)` + `CHECK`.
- Văn bản dài (mô tả, nội dung): `VARCHAR2(4000 CHAR)`; chỉ dùng `CLOB` khi thực sự cần (> 4000 ký tự), map bằng `@Lob`.
- Tìm kiếm không phân biệt hoa thường: `LOWER(col) LIKE LOWER(:kw)`; với cột hay search tạo function-based index `LOWER(col)`.
- Unique theo tòa nhà: `UNIQUE (BUILDING_ID, CODE)`.
- Khoá ngoại luôn có index (Oracle không tự tạo index cho FK).
- Không dùng `@OneToMany` EAGER. Collection dùng `Set` hoặc `List` + `@BatchSize`.

## Flyway

- Đường dẫn: `src/main/resources/db/migration`, đặt tên `V{NNN}__{mo_ta}.sql` (ví dụ `V001__init_auth.sql`, `V010__building.sql`).
- Seed chỉ dành cho local: `src/main/resources/db/seed-local` thêm vào `spring.flyway.locations` của profile `local`, đặt tên `R__seed_*.sql` (repeatable).
- Mỗi bảng: PK, FK có tên (`FK_APARTMENT_BUILDING`), index (`IDX_APARTMENT_STATUS`), CHECK enum, comment `COMMENT ON COLUMN` bằng tiếng Việt cho cột nghiệp vụ.

## API conventions

- Resource số nhiều, kebab-case: `/api/v1/buildings`, `/api/v1/asset-categories`, `/api/v1/asset-items`.
- CRUD chuẩn:
  - `GET /resources?keyword=&status=&...&page=0&size=10&sort=createdAt,desc` → `PageResponse<Summary>`
  - `GET /resources/{id}` → `Response`
  - `POST /resources` → 201 + `Response`
  - `PUT /resources/{id}` → `Response` (gửi kèm `version` để chống ghi đè)
  - `PATCH /resources/{id}/status` → đổi trạng thái
  - `DELETE /resources/{id}` → 204 (hoặc 409 nếu còn phụ thuộc)
  - `GET /resources/export?...` → file `.xlsx`; `POST /resources/import` (multipart) → kết quả từng dòng
  - `GET /resources/options` → danh sách rút gọn `{id, code, name}` cho dropdown
- Filter theo cột ở FE map 1-1 vào query param (`code`, `name`, `type`, `status`, `createdFrom`, `createdTo`...).
- Lỗi: `ProblemDetail` với `type`, `title`, `status`, `detail` (tiếng Việt), `code` (mã lỗi máy đọc), `errors: [{field, message}]` cho lỗi validate. 400 validate, 401 chưa đăng nhập, 403 không có quyền, 404, 409 trùng/xung đột version, 422 vi phạm rule nghiệp vụ.

## Bảo mật

- Đăng nhập bằng username hoặc email + mật khẩu (BCrypt strength 10).
- Access token JWT (15 phút) trả trong body; refresh token (7 ngày) là chuỗi ngẫu nhiên, lưu **hash** ở bảng `REFRESH_TOKEN`, gửi qua cookie `HttpOnly; SameSite=Lax; Path=/api/v1/auth`. Refresh xoay vòng (rotate) mỗi lần dùng; phát hiện dùng lại token cũ → thu hồi cả họ token.
- Khoá tài khoản 15 phút sau 5 lần đăng nhập sai liên tiếp.
- Phân quyền theo permission: `@PreAuthorize("hasAuthority('BUILDING_WRITE')")`. Permission dạng `{MODULE}_{READ|WRITE|DELETE|EXPORT}`.
- `BuildingContext`: filter đọc header `X-Building-Id`, kiểm tra user thuộc `USER_BUILDING` (Admin hệ thống bỏ qua), lưu vào request scope. Service của module building-scoped luôn lấy buildingId từ đây, không tin buildingId trong body.
- Endpoint public: `/api/v1/auth/login|refresh|forgot-password|reset-password`, `/swagger-ui/**`, `/v3/api-docs/**`, `/actuator/health`.

## Upload file

- `POST /api/v1/files` (multipart, field `file`, tham số `purpose`: `BUILDING_IMAGE`, `APARTMENT_IMAGE`, `AVATAR`, `DOCUMENT`, `TICKET_ATTACHMENT`...) → `FileResponse {id, name, size, contentType, url}`.
- Lưu metadata vào bảng `FILE_ATTACHMENT`; file vật lý: `storage/{purpose}/{yyyy}/{MM}/{uuid}.{ext}`.
- Kiểm tra MIME thật bằng magic bytes (không tin extension). Ảnh: jpg/png/webp ≤ 5MB. Tài liệu: pdf/doc/docx/xls/xlsx/ppt/pptx/png/jpg ≤ 20MB.
- Entity tham chiếu file qua id (bảng nối, ví dụ `BUILDING_IMAGE(BUILDING_ID, FILE_ID, IS_COVER, SORT_ORDER)`). Job dọn file mồ côi > 24h (để sau).
- `GET /api/v1/files/{id}` stream file (kiểm tra quyền), `?download=true` để tải về.

## Test

- Unit test service bằng JUnit 5 + Mockito, đặt tên `*Test`.
- Integration test `*IT` dùng `@SpringBootTest` + Testcontainers `gvenzl/oracle-free:23-slim-faststart` (container dùng chung qua `@ServiceConnection` trong `AbstractIT`).
- Mỗi module tối thiểu: test tạo mới thành công, trùng mã → 409, filter/phân trang, không truy cập được dữ liệu tòa nhà khác.
